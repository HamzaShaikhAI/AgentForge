Setup Guide

1. Install as Antigravity Plugin

Copy or symlink the AgentForge directory to ~/.gemini/config/plugins/agentforge/

2. Build the Project

Run npm run build to compile TypeScript

3. Configure Integrations

Set environment variables for bridges that need them (e.g., GITHUB_TOKEN)

4. Restart Antigravity

New plugins are discovered on startup. Restart Antigravity to activate AgentForge.

5. Create Bridges

Add bridge.json files to the bridges/ directory, or use the “+ Create Bridge” button above.
