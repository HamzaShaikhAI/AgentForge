⚡ How AgentForge MCP Works

AgentForge acts as a Local Model Context Protocol (MCP) Server. It exposes deterministic, permission-checked tools to AI agent harnesses like Google Antigravity, Claude Desktop, and Cursor via standard JSON-RPC.

Architecture Flow:
AI Agent (Antigravity)
↓ stdio / HTTP JSON-RPC
AgentForge MCP Server
↓ Permission Gates & Redaction
Windows DPAPI Credential Vault
↓ Safe Execution / Approval Gate
Target Bridge (LinkedIn, Git, etc.)
✓ Local subprocess (zero network latency)
✓ Automatic output token redaction
✓ Strict permission verification (read vs publish)

Action Permission Tier Side Effects Approval Gate Description
profile-me read No Autonomous Verifies OAuth token and fetches member identity & person URN via /v2/userinfo.

GitHub & Local Git Bridge Guide

Local-first repository inspection, atomic commit creation, and remote GitHub release orchestration.

Zero-Config Local

✓ Local Git Operations (Zero Token Required)

AgentForge directly interfaces with your local Git working tree using deterministic child process execution. You can inspect branches, check status, review diffs, and create commits without any external network tokens.

Actions: git-status, git-diff, commit-staged, create-branch

🔐 Remote Operations (Requires GITHUB_TOKEN)

Operations that push branches, publish release tags, or create PRs require a personal access token. Set via environment variable:

$env:GITHUB_TOKEN = "ghp_xxxxxxxxxxxxxxxxxxxx"

All remote write and release operations trigger mandatory operator sign-off.

YouTube & Google OAuth Bridge Guide

Automated video uploading, resumable chunked protocol, quota optimization, and token isolation.

DPAPI Protected

Google Cloud Developer Mode Setup

In Google Cloud Console, create a Desktop App OAuth Client ID and configure the authorized redirect URL to:

http://localhost:8910/oauth2callback

Click Google Dev Mode in the header bar to enter your Client ID.

Safety & Quota Architecture

YouTube video uploading costs 1600 units per execution. AgentForge implements resumable 256KB chunking, exponential backoff retries on HTTP 5xx, and Point-of-Execution Bearer token redaction.

Research topics, search tweets, inspect feed/videos, follow, like/retweet, and publish posts.

1. Developer App Setup

Go to developer.x.com, create a project/app, and open User Authentication Settings.

Set App Type to Native App, and register this Authorized Redirect URL:

http://localhost:43111/callback
3. 1-Click Chrome Login

Click X Config, paste your Client ID, and click Save & Connect. Tokens are saved securely in your Windows DPAPI vault.

Connecting AgentForge to Google Antigravity as an MCP Server

Harness Setup
Step 1: Open Antigravity MCP Settings

Open Antigravity IDE settings or navigate to your project's MCP configuration directory (~/.gemini/antigravity/mcp/).

Step 2: Register AgentForge Server Definition

Add the following entry pointing to your AgentForge working directory:

"agentforge": { "command": "node", "args": ["dist/cli/index.js", "mcp"], "cwd": "C:\\Users\\win10\\Documents\\AgentForge" }
Step 3: Ask Antigravity to Inspect Capabilities

Prompt Antigravity: "Check available AgentForge bridges and list active tools." Antigravity will invoke agentforge_list_bridges and report real live status!

🛡️ Security Boundaries & Human-in-the-Loop Approval Policies

AgentForge enforces strict non-bypassable security invariants at the core runtime level. Every operation belongs to an unambiguous permission level:

read Autonomous

Read-only metadata inspection (git status, list issues, fetch member info). No side effects, no mutations.

local-write Autonomous

Modifications to local working tree (creating branches, staging commits, saving preview drafts). Reversible locally.

external-write Requires Approval

Remote mutations (uploading image assets, creating Linear issues, creating draft releases). Pauses for operator review.

publish / destructive Strict Approval Gate

Public release tags, live social media posting, branch deletion. Requires explicit operator identity sign-off.
